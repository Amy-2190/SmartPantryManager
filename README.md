# Smart Pantry Manager

## About the Application

Smart Pantry Manager is a Java Android application developed for the Mobile App Development 700 assignment.

The purpose of the application is to help users keep track of the ingredients they currently have in their pantry and find recipes that they can make using those ingredients and reduce food waste.

The application allows users to add, edit, view and delete pantry ingredients. It also checks the ingredients in the pantry against the available recipes and only suggests a recipe when all of the required ingredients and quantities are available.

## Main Features

* Add ingredients to the pantry
* Edit existing pantry ingredients
* Delete pantry ingredients
* View pantry ingredients using a RecyclerView
* Store pantry information using SQLite
* 20 preloaded recipes
* Suggest recipes based on the current pantry
* Strict recipe matching using required ingredients and quantities
* View recipe ingredients and preparation instructions
* Settings screen
* Basic input validation
* Pantry data remains available after closing and reopening the application

## Database

SQLite was selected as the database for this application.

SQLite is built into Android and does not require a separate database server or an internet connection. This makes it suitable for a small Android application such as Smart Pantry Manager. It also allows the application to store the pantry and recipe information locally on the device.

## How to Run the Application

1. Clone or download the Smart Pantry Manager project from GitHub.
2. Open the project in Android Studio.
3. Allow Android Studio to complete the Gradle sync.
4. Start an Android emulator or connect an Android device.
5. Run the application from Android Studio.
